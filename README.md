# Division Records System downloads

Signed Android downloads. These public APKs contain no workspace or enrollment credentials.

- [DRS Super 1.0.1](https://github.com/gragaza-creator/DRS-downloads/releases/download/super-v1.0.1/DRS-Super-v1.0.1.apk): separate app with section switching.
- [Standard DRS Android 0.2.7](https://github.com/gragaza-creator/DRS-downloads/releases/download/android-v0.2.7/DRS-Android-v0.2.7.apk): office scanner.
- [Separate Super setup package](https://github.com/gragaza-creator/DRS-downloads/releases/download/super-v1.0.1/DRS-Super-Setup-v1.0.1.zip): prepares an authorized configured download on the Records computer.

Both apps use the supplied division seal as their launcher icon and contain the Android launch callback fix. Android 8.0 or later, ARM64/ARM32 and Google Play services are required. Phone launch, camera and Google acceptance remain pending.

Install updates over the existing app to preserve enrolled access and queued actions. A fresh installation needs a configured download QR from Records. Keep configured operator/office links separate from these public binaries.
